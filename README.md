# 🚀 Hirrd – Job Portal

A modern, full-stack job portal built with **React**, **Shadcn UI**, and **Supabase**, inspired by [RoadsideCoder's Hirrd Project Tutorial](https://www.youtube.com/@RoadsideCoder).  
Users can post, search, and apply for jobs with a clean UI and real-time database integration.

---

## 🧠 Features

✅ User authentication (Sign up / Login) via **Supabase Auth**  
✅ Create and delete job postings  
✅ Browse & filter available jobs  
✅ Responsive and accessible design using **Shadcn/UI components**  
✅ Real-time data sync powered by **Supabase**  
✅ Deployed on vercel -> https://hirrd-job-portal-two.vercel.app/

---

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/hirrd-job-portal.git
   cd hirrd-job-portal
2. **Install dependencies**
      npm install

3. Create a .env file in the root directory:
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   
4.Start the development server    ->   npm run dev

5. Open in browser  -->  http://localhost:5173

6. 🌍 Live Demo
